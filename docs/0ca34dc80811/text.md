                                     .2 מהות גישת "דרכים שמסבירות את עצמן" ומטרותיה

"דרכים שמסבירות את עצמן" היא גישה שמתמקדת בשימוש בעיצובי דרכים שמיועדים להניע את
משתמשי הדרך להתנהגויות בטוחות, לצמצם טעויות אנוש ולשפר את רמת הבטיחות. לגישת
"דרכים שמסבירות את עצמן" ישנן ארבע מטרות: אספקת מידע חזותי למשתמשי דרך, יצירת מבנה
ומראה ייחודיים ואחידים לכל הדרכים ברשת בהתאם להיררכיית רשתות הדרכים (לדוג': דרכים
בינעירוניות מהירות, דרכים בינעירוניות לא מהירות וכן'), התאמת התנהגות משתמשי הדרך
                   לסביבה בכלל ולמאפייני הדרך בפרט, ויצירת תשתית סלחנית לטעויות אנוש.

.4 מנגנון ההשפעה של דרכים שמסבירות את עצמן
לפי תיאורית התפיסה ( )perception theoryשל גיבסון (,)Gibson, 1986; Helmers, 2014
המידע שאנחנו צריכים על הסביבה שלנו כבר נמצא "שם בחוץ", ומשם מידע זה נקלט למוח דרך
החושים (ראיה למשל). מהרגע שהמידע נקלט למוח דרך החושים כבר אפשר לקבל תמונה על
הסביבה, המראה שלה, וממה היא מורכבת. בנוסף, זה גורם לאדם לנבא ולצפות מה יכול להתרחש
