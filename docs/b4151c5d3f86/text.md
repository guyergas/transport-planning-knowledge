 הוראות התקנה

בצע/י גיבוי לאוגדנים עימם את/ה עובדים.

בצע/י גיבוי של קובץ Workspaces.accdb / Workspaces.mdb הנמצא בתיקיית ענב"ר.

הסר/י גרסת ענב"ר נוכחית (במידה ומותקנת).

יש להתחבר למחשב כ-Administrator.

פתח/י את התוכן קובץ ההתקנה לתיקייה זמנית חדשה.

בתוך התיקייה הזמנית הפעל/י את קובץ ההתקנה – DistributeInbar.exe עם קליק ימני -> Run as administrator

ההתקנה לוקחת מספר דקות, יש להמתין להופעת הודעת "התקנת ענב"ר הושלמה"

בתום ההתקנה יש להעתיק את הקובץ Workspaces.accdb/mdb לתיקייה התקנה של ענב"ר. במידה ומדובר בהתקנה במחשב חדש, ניתן להוריד את הקובץ בלינק המצורף למעלה.

הפעל/י את מערכת ענבר.

בחר/י מחדש או הגדר/י את האוגדן עמו את/ה עובד.

בצע/י התחברות אל בסיס הנתונים.
